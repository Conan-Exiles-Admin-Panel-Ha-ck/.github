## 📜 CONSOLE COMMANDS — `TILDE → /COMMAND → ENTER`

Text-based commands for precise control over every aspect of the game.

- **Enable Admin Mode** — use `MakeMeAdmin` with the admin password on private servers, or enable admin tools in single-player 
- **Open Console** — press `~` (tilde) to open the command console 
- **Spawn Item** — `/SpawnItem [ItemID] [Quantity]` spawns the specified item directly into your inventory 
- **Spawn NPC / Creature** — `/Spawn [CreatureID]` spawns a creature or NPC at your location 
- **Teleport** — `/Teleport` and related commands for fast travel 
- **God Mode** — `/God` toggles invulnerability 
- **No Building Costs** — `/NoBuildingCosts` enables Creative Mode with infinite building materials 
- **Player Management** — commands for kicking, banning, and managing players on your server 

`TILDE → COMMAND → EXECUTE`
